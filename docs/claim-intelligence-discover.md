# V5.04 — primary evidence and fact-check discovery

Experimental internal API, no registry or production changes. `discover_claim_evidence(graph, claim_id=..., queries=(), news_phrase=None, review_captures=(), permit_review_metadata=False, execute=False, cache=None)` revalidates one V5 claim graph and plans caller-selected searches. No query is automatically dispatched from a claim or untrusted source. Explicit execute opt-in only. Every result is a candidate, not supporting or contradicting evidence.

Existing fixed-origin, keyless adapters reused with env={} (no credential lookup):
- World Bank indicator with explicit ISO two-letter geography and indicator ID: exact returned country/indicator, reported year and value, preserving null and zero separately.
- GLEIF legal-name search: returned LEI, legal name, entity and registration statuses; not verified identity, ownership or financial performance.
- EU Cellar legal-title search: exact work identifier and title; metadata not proof of current law or applicability.
- Optional existing V4 Google News keyword search (max five records); unknown independence, no automatic extraction.

One operation per official source, up to three, max ten selected rows each; existing collector quotas/caches apply. Scope mismatch and malformed rows rejected, source errors remain unavailable, count is adapter sample not completeness. No arbitrary source URLs or new network transport. No raw provider payload in discovery result. The underlying existing collector's bounded cache behavior is unchanged; dataset-specific rights still apply. Query values must be public and non-sensitive.

Fact-check discovery: `parse_review_capture(raw, format=..., captured_at=..., permit_metadata=True)` imports explicitly permitted saved Google Claim Search JSON or literal ClaimReview JSON-LD (single object, array, or @graph). Preserve exact attributed publisher, original reviewed claim, claimant/date, URL, review date/language and original textual/numeric rating/scale. No remote context resolution, pagination follow-up, source fetch, rating normalization, or semantic match. Missing/empty/invalid and partial pages are distinct; pagination token is not retained. Three imported captures at most, each 256 KiB, up to 20 Google claims and 40 review rows. Caller establishes retention rights; no source authentication, raw body storage or fact verdict. Google live Claim Search is disabled: official read-only method and terms documented, but a guaranteed free authenticated allowance has not been verified. No API key creation or use, billing, scraping or ClaimReview write access.
