## What to do next, in gate order

1. **A05 — get independent labels** before improving ranking algorithms. Each case needs original public evidence URLs; `source_published_at` and `source_observed_at` at/before its historical cutoff; a later independently substantiated ground-truth outcome and date; a reviewer attestation; both v1 and v3 actual ranks and reviewed citations. Do not score unknown/unreviewed as negatives. Without 20 usable comparable cases, output **metrics unavailable**.
2. **B09 — find valid real cross-domain lineage under a v1-accepted evidence source contract.** The current GitHub Release ↔ PyPI distribution demonstration answers an event-identity question, but cannot justify adding a general confirmation counter to existing v1 opportunity ranking. Keep B09 offline-only until real accepted inputs show a measurable benefit. Discard if none exists.
3. **B08 — provision the official runner via an approved isolated transport/runtime that is demonstrably capable of resolving its dependency graph.** Do **not** repeatedly restart Codexify or retry unchanged npm/Bun/Yarn installs. No GitHub workflow edits, host-wide packages or public listener without review. Existing independent Python SDK HTTP checks are supportive but **not** official conformance.
4. **A04/A10 — run blinded externally adjudicated *real workflow* comparisons** and review source-specific lawful reuse/attribution. Source compatibility and test coverage alone do not establish user productivity or commercial research utility.
5. **A09 — obtain rights clarification or discard. A11 — remain discarded.** Fourteen other B-series items (B05, B06, B10, B18, B19, B20, B22, B23, B24, B26, B27, B28, B29, B30) are **research-only, not implementation-authorized** under the canonical plan.
